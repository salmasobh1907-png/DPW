No AI or model inside the tool

Every feature is a fixed rule written in JavaScript: keyword matching for emails, formulas for profit and transit days, date checks for validity. Nothing is sent to an AI service.

  • Checked on every change. An automated test (tests/rules.test.js) fails if the page calls an AI or language-model service, or loads code from any host that is not on the allowed list.
  • Allowed outside hosts today: cdnjs.cloudflare.com (pdf.js 3.11.174, SheetJS 0.18.5, jsPDF 2.5.1 + autotable 3.8.2) and Google Fonts. IT can host these files inside DP World instead; the tool then calls no outside host.
  • Mail links only open a draft. A person always presses Send in Outlook.
Prototype parts IT replaces. The demo saves data through its prototype host (window.claude: shared store, file download, test-mail connector, viewer name). These are storage and login services, not AI. In production they become: the team database, a normal browser download, the Graph mail job, and Entra ID sign-in.

Questions for the BTI session

  1. Which values can Contract Type hold? The tool counts only rows where it is empty or "Standard" as the lowest rate.
  2. How is the Rate ID / reference number built, and who assigns it?
  3. Can the Rate Bank get a POL Terminal column for Sokhna (DP World terminal or other)? Today the tool guesses it from the carrier name.
  4. What date format does Validity use? An empty validity means the end of the rate's month.
  5. Who updates the Rate Bank, and at what times, so the refresh job runs after them?
  6. Does NPM offer an API, and who owns it?

Decisions IT makes

  1. Hosting: SharePoint + Power Automate, Power Apps + Dataverse, or Azure Static Web App + Functions + SQL. With the Azure option the buy rates stay on the server and only reach the Pricing group.
  2. Service account for the refresh job and the mail job.
  3. Security review before any real data enters the tool.
  4. HR and Legal view on the "My shift" time tracking.
  5. New shared mailboxes: IT creates them in Microsoft 365 (for example a reefer box); Pricing then adds them in the tool with SLA, access and routing words.
  6. WhatsApp: whether DP World opens a WhatsApp Business Platform number for carriers. The tool never reads a personal WhatsApp.
  7. Allowed link hosts for the Data sources screen (SharePoint, carrier portals, internal APIs).
