How we know it works

Six measures, baseline first

Time to quote

Email received to draft saved, in working hours

Replies within SLA

Share of cases answered inside the mailbox SLA

Win rate

Won quotes over decided quotes

Margin per box

Sell minus buy on won quotes, against the 3 months before

Hand-offs per case

Forwards and reassigns before the reply

Quote errors

Quotes from a special, spot or other-terminal rate by mistake

Safeguards stay on: the tool never sends email, Sales never see buy rates, every quote has a check code, sources are read only.

All six come from the tool’s own log, so nobody fills a spreadsheet to report them.
