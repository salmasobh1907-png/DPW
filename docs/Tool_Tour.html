11 · Built-in control

Safe by design

What the tool will never do, whatever the screen.

No AI inside

Plain rules: keywords and formulas, as IT asked.

Never sends email

It saves a draft; a person checks it and presses Send.

Sales never see buy rates

Buy and profit stay with the Executive role.

Sources read only

The Rate Bank and mailboxes are read, never written.

Check code on every quote

An edited copy is caught by Verify.

No passwords stored

Carrier sites are opened by the person, who logs in.
